## ICO

|      尺寸 | 用途                        | 现代 ICO 建议 |
|--------:|---------------------------|:---------:|
|   16×16 | 小图标、详细信息视图、标题栏            |   ✅ 必须    |
|   20×20 | 125% DPI 小图标              |   ⚠️ 推荐   |
|   24×24 | 150% DPI、小工具栏             |   ⚠️ 推荐   |
|   32×32 | 标准图标、任务栏、小图标              |   ✅ 必须    |
|   40×40 | 200% DPI 下的 20px 资源       |   ⚠️ 可选   |
|   48×48 | 资源管理器中等图标、旧系统常用           |   ✅ 推荐    |
|   64×64 | 高 DPI 中间尺寸                |   ⚠️ 可选   |
| 128×128 | 大图标、部分旧场景                 |   ⚠️ 可选   |
| 256×256 | Explorer 大图标、Vista+、高 DPI |   ✅ 必须    |

## ICNS

|        尺寸 | ICNS 类型 | 用途                      | 现代 ICNS 建议 |
|----------:|---------|-------------------------|:----------:|
|     16×16 | `icp4`  | Finder 小图标、列表视图         |   ⚠️ 可选    |
|     32×32 | `icp5`  | 小图标 Retina 对应           |   ⚠️ 可选    |
|     64×64 | `icp6`  | 32×32 @2x               |   ⚠️ 可选    |
|   128×128 | `ic07`  | Finder、Dock 小尺寸         |    ✅ 推荐    |
|   256×256 | `ic08`  | 128×128 @2x、大图标         |    ✅ 必须    |
|   512×512 | `ic09`  | 256×256 @2x             |    ✅ 必须    |
| 1024×1024 | `ic10`  | 512×512 @2x、Retina 最大尺寸 |    ✅ 必须    |
